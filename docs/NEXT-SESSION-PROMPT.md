# Next-session prompt

This file used to carry a hand-written prompt for the next session. It went stale, so it now only
points at the live state.

To resume work, start a session in the repository root and read, in this order:

1. [`AGENTS.md`](../AGENTS.md) — the rules every agent and session follows.
2. [`docs/PLANNER.md`](PLANNER.md) — read **"▶ Resume here"** first, then §0 (the product goals)
   and §3 (the task board).
3. The task specs and agent reports in [`docs/tasks/`](tasks/) that the planner names.

If the planner and the code disagree, the code wins.
