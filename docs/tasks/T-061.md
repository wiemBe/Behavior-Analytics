# Task T-061 — Phase A pages must ask for Phase A anomalies only (regression from T-057)

Read `AGENTS.md` at the repository root first and follow it exactly (§1 scope, §4 tests).

## The defect

Since T-057, `GET /api/v1/anomalies` returns Phase A **and** WAF anomalies when the query has no
`subject_kind` (see `docs/tasks/T-057.report.md`, "Filter by kind"). Two existing Phase A pages
call it without `subject_kind`:

- `frontend/src/app/behavior/page.tsx`: `api.anomalies({ active_only: true, limit: 50 })`;
- `frontend/src/app/behavior/sources/[id]/page.tsx`:
  `api.anomalies({ log_source_id: id, limit: 20, since, until })`. Here `log_source_id` does not
  help: it matches a WAF endpoint's log source too.

On an install with WAF anomalies, these pages render WAF rows with Phase A components, in EPS.

## The fix

1. `frontend/src/lib/api.ts`: add one optional field to `AnomalyListParams`:
   `subject_kind?: "LOG_SOURCE" | "WAF_ENDPOINT";` (the backend enum `SubjectKind` in
   `backend/app/schemas/anomaly.py`). Change nothing else in that file.
2. Both pages above pass `subject_kind: "LOG_SOURCE"` in those calls. Change nothing else in them.
3. Audit every other caller of `api.anomalies` under `frontend/src` (not tests). Today the only
   other one is `frontend/src/app/anomalies/page.tsx`, the unified list, which **must stay
   unfiltered**: do not change it. Report what you found.

## Tests

In `frontend/src/app/behavior/page.test.tsx` and `frontend/src/app/behavior/sources/[id]/page.test.tsx`
add **one new test each** asserting that `api.anomalies` was called with an object containing
`subject_kind: "LOG_SOURCE"` (use `expect.objectContaining`). Follow how each file already mocks
`api`. Do not change any existing test.

Then break the fix on purpose (remove `subject_kind` from one page), run that page's test file,
confirm the new test fails, and restore the fix. Do the same for the other page.

## Allowed files

Exactly these five: `frontend/src/lib/api.ts`, `frontend/src/app/behavior/page.tsx`,
`frontend/src/app/behavior/page.test.tsx`, `frontend/src/app/behavior/sources/[id]/page.tsx`,
`frontend/src/app/behavior/sources/[id]/page.test.tsx`.
