# Task T-091 — the frontend image installs the tested lockfile; free patch upgrades

Read `AGENTS.md` at the repository root first and follow it exactly. Read
`docs/tasks/T-088.report.md` (the `npm audit` triage) in full before you change anything.

## Why

1. **The production image ignores the lockfile.** `frontend/package-lock.json` is committed, but
   `frontend/Dockerfile` copies only `package.json` and runs `npm install`. The comment there says
   "No lockfile committed in this scaffold", which is no longer true. So every image build
   resolves fresh versions: the image is not what the gates tested, and a compromised or broken
   release can enter it unreviewed.
2. **T-088's patch-level recommendations.** None of the 22 audit findings is reachable here, but
   the patch upgrades are free, and they clear every critical and most of the highs.

## Build

1. `frontend/Dockerfile`, deps stage:
   - copy `package.json` **and** `package-lock.json`, and run `npm ci`;
   - replace the stale comment with one that says why.

   Keep every other stage as it is.
2. In `frontend/`, the upgrades. **No major upgrade.**
   - `next` → `15.5.28`, pinned as the current spec style pins it.
   - `echarts-for-react` → `3.0.6`.
   - `sharp`: if it is in the lockfile as Next's optional dependency, make the lockfile resolve
     `0.35.5` or later within Next's declared range. Otherwise leave it alone.
   - `npm update` within the existing ranges, for the transitives T-088 lists as fixable that way
     (`nanoid`, `source-map-js`, `browserslist`, `baseline-browser-mapping`, `js-yaml`,
     `brace-expansion`, the vite-nested `postcss`).
   - **No `overrides` entry for Next's pinned `postcss`.** It is build-time only and unreachable,
     and overriding Next's exact pin is a risk this task does not take. Record it as accepted.
   - No `vitest` 4 and no `echarts` 6 (planned separately). Never run `npm audit fix`.
3. Record before and after `npm audit` counts, full tree and `--omit=dev`, in the report.

  - Confirm `node_modules/next/package.json` inside the image is `15.5.28`.

- Start the built standalone server **outside Docker** (`npm run build`, then
  `node .next/standalone/server.js` on port 3191) and confirm `/` and `/anomalies` answer 200.
  Stop it by PID.
