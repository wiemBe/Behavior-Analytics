### Custom properties applying to the new types (type-wide, enabled expressions)

- **FTD (448): none.** The catalog join returned no property for this type.
- **PAN (206): nine**, none action-, signature- or severity-like: Application, Bytes, Bytes
  Received, Bytes Sent, Destination Zone, Object Name, Object Type, Source Zone, URL.
- Measured on the PAN events for the six string properties (Application, Source Zone, Destination
  Zone, Object Name, Object Type, URL): **0.0 % populated**. The QRadar expressions are written for
  the LEEF/CEF forms of the DSM and do not match the raw CSV the generator sends. The three numeric
  properties were not queried.

### Is block versus allow visible?

- **No dedicated property or normalized field** carries it on either product (T-027 §6 stands). The
  catalog shows no action property for either type.
- **FTD:** no. Category and QID name depend on the signature only, and severity is a constant 10.
  `AccessControlRuleAction` and `InlineResult` are not reaching any queryable field.
- **PAN:** the category varies (for example "Alert" and "Information" both appear under the QID
  "URL Filtering"), but the generator does not log which events it sent as `drop`, so this run
  cannot tie category to the action. Treat it as **unproven**, not as an action signal.
- **Consequence for Phase D:** an IPS action detector needs a custom property authored by the
  operator (in the UI, against the real payload). Until then action-dependent validation stays
  INSUFFICIENT_DATA.

## Open points

- The lab events are deterministic and index-cyclic (T-029), so these numbers show that fields
  parse, not how a real FTD/PAN fleet behaves. Real action and severity coverage needs production
  sources.
- The FTD key order and several keys are still UNVERIFIED against a real device (T-029). The DSM
  parsed this rendering, which is evidence for the rendering only.
- The PAN custom properties likely populate on LEEF/CEF input; that was not tested.
- Both sources now exist on the lab console and are enabled, as the user intended. They will go
  stale (status ERROR) when no traffic is sent.
