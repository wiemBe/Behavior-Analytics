## 2. What I did
**VolumeChart.** No marker on every point (`showSymbol:false`); a lone measured bucket between gaps gets a `markPoint`. Expected range is one neutral band (invisible stacked floor plus filled series) with the median as one thin dashed line; the three green lines are gone. Colours: I chose the **runtime helper** (`readChartPalette()` reads tokens via `getComputedStyle` in the effect, since the component is also SSR-rendered). `chartPalette.test.ts` asserts every token it names is declared in `tokens.css`, and the chart test asserts the option contains no hex/rgb literal. ECharts legend replaced by a markup key that lists only marks actually drawn (observed, median, range, not-fully-collected, anomaly, transition); `LegendComponent` dropped, `MarkPointComponent` added (registration count still 7). Y axis "Events per second (EPS)", x axis "Time (UTC)" with `useUTC`.
**Incident page.** Identity line (detector at 26 px, state, severity, UTC interval with `<time>`) first; source name is the h1 at 16 px, wraps anywhere. Four KPI cards replaced by one `.measure` block: observed (largest, EPS), expected (EPS), deviation (ratio plus signed absolute delta in events), duration (em dash and "Still running" when open); "Detector confidence (0 to 1)" is the block footer carrying the existing limitation text.
**Audit fixes.** Times are now always UTC and say so (`2026-10-12 09:15:00 UTC`, compact `10-12 09:15 UTC`; previously locale/server-timezone with no zone, a hydration hazard). Anomaly time filter: zoneless input read as UTC (was server-local), field now keeps its value after submit (ISO value was invalid for datetime-local, so it came back blank), visible "(UTC)" labels. Detector names consistent (`Volume drop`, not `VOLUME_DROP`) in tables, filters, chips, chart. Units on numeric headers (EPS, events), numeric columns right-aligned with tabular figures, long source names capped/wrapped in tables. `sevTone`: LOW no longer green (now info; unknown neutral). Seasonal cell shown as `Mon 12:00 UTC` instead of "Weekday 1, hour 12". Health bar is SVG (inline style removed). Loading and error states added for both route trees. Overview/sources/anomalies descriptions no longer restate the heading; they state scope and timezone. Action links styled as secondary buttons. Two section-head spacing fixes.
