## Build

1. **`IpsDimension`** (new StrEnum in `app/models/enums.py`, IPS-only): `TOTALS`,
   `DESTINATION_PORT`, `DESTINATION_IP`, `SIGNATURE`, `SOURCE_IP`, `PORT_FANOUT`, `ACTION`.
2. **Search plan** — `app/ips/collection_plan.py`, pure. Input: a list of
   `(qradar_log_source_id, IpsFieldMapping)` for enabled, `VALID` sources. Output, per dimension,
   groups of source ids that share the exact field references that dimension needs (§D.5: sources
   with all-normalized defaults form one group; a custom property makes its own group).
   - `TOTALS` is one group of every source.
   - `ACTION` covers only sources with `ACTION` mapped.
   - `DESTINATION_PORT` uses `PROTOCOL` when it is mapped.
   - A group holds at most `ips_max_sources_per_search` sources. A larger group is chunked
     deterministically.
   - Output order is deterministic: dimension order, then the sorted reference tuple, then the
     source id.
3. **Provider method** (base, REST and mock; read-only; `AQL_EXECUTION` required; MCP unsupported)
   — one method, `get_ips_keyed(dimension, *, qradar_log_source_ids, fields, window_start,
   window_end, bucket_seconds, max_rows) -> IpsKeyedResult` (DTO in `app/providers/dto.py`):
   - `fields` is a mapping of logical field → `(kind, name)`. Validate every reference again in the
     provider (allowlist or `PROPERTY_NAME_PATTERN`) before quoting it. Ids are ints. Validate the
     window with `validate_bucketed_metric_window`. Cap the source count at
     `ips_max_sources_per_search`.
   - AQL per the §D.5 table:
     - bucket key `starttime / {bucket_ms}` selected as `"k"` and grouped;
     - `logsourceid IN (…)` and the half-open `starttime` bound in `WHERE`, plus
       `self._ariel_scope(...)`;
     - `LIMIT max_rows + 1`; volume is `SUM(eventcount)`, and `COUNT(*)` is provenance only;
     - `ORDER BY` volume `DESC` (fan-out: by the `UNIQUECOUNT` `DESC`);
     - filters from `_ips_population_condition`: port `> 0`; the destination IP and source IP
       populations; `qid > 0` for a normalized signature; `IS NOT NULL` for a custom property;
     - fan-out is `UNIQUECOUNT(<port>)` with the port `> 0` filter, grouped by source, source IP
       and key;
     - for a normalized `qid`, select `QIDNAME(qid)` as the display name;
     - **no `CASE`.**
   - Result: rows with `qradar_log_source_id`, `bucket_start`, the dimension's values, `events`,
     `records` (and `distinct_ports` for fan-out, `name` for a normalized signature), the rows'
     `truncated` flag (more than `max_rows` rows; keep the first `max_rows` rows), and the window
     and source set searched.
   - Any key outside the window, any non-integer key, or any `logsourceid` outside the requested
     set fails the whole search with a `ProviderError`. Nothing upstream goes into an error message.
   - The mock provider implements the same method deterministically, honouring the window and
     sources. It needs a way for tests to force truncation and failure, so the real fold and driver
     run in unit tests (§SC.5 rule 6).
4. **The split driver** — `app/ips/keyed_search.py`:
   `async run_dimension(provider, dimension, group, window, bucket_seconds, *, max_rows, budget)`.
   It returns a per-`(source, bucket)` outcome for that dimension.
   - **Truncated:** if the window has more than one bucket, split it into two halves of whole
     buckets, left half first. Otherwise, if there is more than one source, split the sources into
     two halves. Otherwise (one source, one bucket) keep the first `max_rows` rows: the top is exact
     and the tail is missing, so the measurement is **`LOWER_BOUND`** (§D.5).
   - **A truncated multi-bucket or multi-source result keeps nothing.** Never write a cell from it.
   - **Failed** (`ProviderError` other than a rejection): every cell of that search is `FAILED`.
     Do not split; retrying a failing appliance multiplies the load.
   - **Rejected** (`ProviderQueryRejectedError`): every cell is `REJECTED`. The rejection's text is
     never kept (§D.8); log it by class only.
   - **Budget:** a tick-wide search budget object, shared across dimensions, that T-050b sizes.
     When it is exhausted, every remaining cell is `NOT_COLLECTED`, never zero.
   - **Provenance** per cell: `search_window_start`, `search_window_end`, `search_bucket_count`,
     `search_source_count`, `split_depth` and `bucket_key`.
   - A source with no row in a `COMPLETE` search has a **measured zero** for that dimension in that
     bucket. That is only true when the search itself was complete; a zero from any other state is
     a bug.
5. **The folds** — `app/ips/fold.py`, pure. Per `(source, bucket, dimension)` outcome →
   facts:
   - `TOTALS`: events and records.
   - **Entity dimensions** (`DESTINATION_PORT`, `DESTINATION_IP`, `SIGNATURE`):
     - the top `ips_max_entities_per_bucket` entities by events, ties broken by `value_key`;
     - `dimension_events`, the sum over **every** row, not just the top;
     - `unattributed_events`;
     - the measurement (`EXACT` | `LOWER_BOUND`).

     The `value_key` rules (§D.4):
     - **Port:** `"<port>/<proto>"`. `proto` is `tcp` (6), `udp` (17), `icmp` (1),
       `ipv6-icmp` (58) or `sctp` (132); any other 1–254 is its number; `0`, `255`, null or
       unmapped is `unknown`. Port `0` is never an entity; it is excluded in the query, and the fold
       asserts it.
     - **Destination IP:** canonical text through `ipaddress`. An unparseable value is not an
       entity; it counts in `unattributed_events` (the T-013 rule).
     - **Signature:** `qid:<int>` for a normalized qid, `sig:<value ≤ 128 chars>` for a custom
       property. The QID name is display-only, with a `generic_name` flag when it starts with
       `"Unknown "`.
   - `SOURCE_IP`:
     - `source_events`;
     - `distinct_sources`, the row count (a lower bound under `LOWER_BOUND`);
     - `top1_events` and `top5_events`;
     - **contributors: at most 10 `(ip, events)`.** Source IPs are never entities.
   - `PORT_FANOUT`: the largest distinct-port count of one source IP, and contributors (at most 10
     `(ip, distinct_ports)`).
   - `ACTION`: `blocked_events`, `allowed_events` and `unmapped_events` through the profile's value
     map, matched by `_action_key`. **An unmapped value never counts as allowed.**
   - **Coverage** per dimension is `dimension_events / totals.events` (§D.5). It is `None` when
     totals are missing, failed or zero. **It is never 0 from a missing input.** Under
     `LOWER_BOUND` it is flagged a lower bound.
6. **Settings** in `app/core/config.py`, bounded, in the WAF style:
   - `ips_max_sources_per_search` (default 50);
   - `ips_max_entities_per_bucket` (per source, per dimension, default 200).

   Reuse `ariel_multi_bucket_max_rows` for `max_rows`.

## Tests (pin every guard and exit path)

- **AQL text per dimension:** quoting of a normalized field against a custom property; every
  filter; `LIMIT n+1`; the padded scope; the `GROUP BY` with the key; no `CASE`; `QIDNAME` only for
  a normalized `qid`.
- **Provider guards:** unaligned window; too many sources; a bad reference; a key outside the
  window; a non-integer key; an unexpected `logsourceid`; the truncation flag at `max_rows` and at
  `max_rows + 1`; mock parity; MCP unsupported.
- **Plan:** grouping by references; `ACTION` only where mapped; chunking; deterministic order.
- **Driver:**
  - time is split before sources;
  - the one-source, one-bucket base case yields `LOWER_BOUND` with the top kept;
  - a truncated wide search keeps nothing;
  - failure gives `FAILED` with no split, and rejection gives `REJECTED` with no text stored;
  - an exhausted budget gives `NOT_COLLECTED`;
  - a measured zero comes only from a `COMPLETE` search;
  - provenance is recorded.
- **Equivalence (the acceptance bar, §SC.5 rule 4):** for random windows and source sets on the
  mock, with forced truncations, the keyed path with splits gives per-cell facts equal to running
  every `(source, bucket)` alone, apart from provenance.
- **Folds:**
  - the protocol map and `unknown`;
  - no port-`0` entity;
  - an invalid IP is unattributed;
  - top-N ties;
  - `dimension_events` over all rows;
  - coverage `None` against a measured `0`;
  - contributors capped at 10;
  - an unmapped action never counts as allowed;
  - `LOWER_BOUND` carried through to `distinct_sources` and coverage.
- Break each guard on purpose, see a test fail, restore.
