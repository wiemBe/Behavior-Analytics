# Task T-092 — `test_behavior_bulk_reads.py` fails when a run crosses a UTC hour

Read `AGENTS.md` at the repository root first and follow it exactly. Tests only: no file under
`backend/app/`.

## The defect

`backend/tests/integration/test_behavior_bulk_reads.py` sets, at **module import**:
- `NOW = datetime.now(UTC)`;
- `EARLIER = NOW - 2 h`.

The tests seed baseline cells keyed on NOW's `(isoweekday, hour)` and then call
`/api/v1/anomalies/summary` and `/api/v1/behavior/sources`. Both routes judge each source against
the cell of the **current** hour at request time.

pytest imports every module at collection, before the first test runs. The full integration
suite takes about 13 minutes. When the run crosses a UTC hour between collection and this test,
the seeded cells belong to the previous hour and the counts change.

The full gate on `0ecfd7d` (2026-10-14, started ~18:59 UTC) failed
`test_summary_counts_reliable_unreliable_and_missing_cells` this way. The same file passed
6 of 6 alone a few minutes later. Any test in the file that seeds at `NOW` and reads the current
hour has the same exposure.

## Build

Make every test in the file use a NOW taken **when the test runs**, and immune to an hour boundary
**during** the test:
- Replace the module-level `NOW` and `EARLIER` with a fixture (or a helper called at the start
  of each test) that reads the clock then.
- If less than ~60 s remain before the next UTC hour, wait until the hour has turned before
  seeding (bounded: at most 61 s), so seeding and the request see the same hour. Say in a
  comment why.
- Alternatively, patch the clock the app's routes read, if they go through one function you can
  override in the test (look for how `/anomalies/summary` gets "now"). Prefer this if it is
  clean: it makes the test deterministic. Use the app's existing seam if there is one. **Do not
  add one to `backend/app/`.**
- Keep every assertion and every test's intent byte-for-byte the same. Change only how NOW is
  obtained and passed to the seed helpers.

Then look for the same pattern in the other test files: a module-level `datetime.now(...)` used
to seed data that a route judges against the current hour or day. **List every occurrence in the
report. Do not change them**; the orchestrator will rule.
