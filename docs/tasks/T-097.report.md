### Error tests (9 files)

Each renders the route's default export with `error={Object.assign(new Error("secret stack"), { digest: "ref-97" })}` and a `reset` spy, and asserts the file's own words:

- the alert names what failed — e.g. `"Classification rules could not be displayed."`;
- it says what the analyst can do — `"Nothing on it was changed."` and
  `/check that the backend is reachable/i`;
- the digest is shown as `Reference: ref-97.`, and the raw exception text (`"secret stack"`) is not;
- a second case pins the `digest` guard (no `Reference:` when there is no digest) and that the
  `Try again` button calls the `reset` prop exactly once.

### Loading tests (2 files)

Each renders `./loading` and asserts it exposes a busy state to assistive technology
(`role="status"`, `aria-live="polite"`) with its own words (`"Loading anomalies…"`,
`"Loading behavioral analytics…"`), and that while it waits it renders **no data** (no table), **no
`No results` text**, no alert, and no zero.
