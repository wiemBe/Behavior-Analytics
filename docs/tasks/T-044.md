## Designed states (every one gets a Vitest test)

- List: loading; error (what failed, what to do); empty (§FM.8 copy, with the Add action); rows in
  every validation state (`UNVALIDATED`, `VALID`, `INVALID`, `INCONCLUSIVE`, pending, version not
  validated) and both collection states.
- Editor: loading; 404 (no profile for this source → offer to create one); error; create mode with
  prefill from a VALID profile and from schema defaults (says which); save confirmation with the
  changed-fields list; 201/200 success (pending appears); 409 concurrent change (edits kept);
  422 (server message shown at the field or form); 403 (the role lacks `admin:waf`); validate 409
  while pending; enable refused (reason shown); catalog `UNAVAILABLE` (free text, reason shown);
  a name not in the catalog; a name not for this source type; a `name_allowed: false` entry shown
  as not selectable; validation report with each field status including `NO_EVENTS` and
  `QUERY_FAILED` (rendered as "says nothing about the field", never as failure of the field);
  truncated discovered values; history empty and filled.
- Honesty: a missing measurement (null share, null total) renders as an em dash with its meaning,
  **never as 0 %**. Times in UTC with the zone shown. Percentages and counts right-aligned with
  tabular figures in tables.

After writing each guard test, break the code on purpose, see it fail, then restore.
