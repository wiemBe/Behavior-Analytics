# Task B-1.3 Report — `GET /api/v1/me`

## Files Changed

1. **backend/app/schemas/me.py** (new): Created `MeOut` Pydantic model with `subject`, `email`, `permissions`, and `effective_permissions` fields.

2. **backend/app/api/routes/me.py** (new): Created router with `GET /me` endpoint that returns the authenticated caller's identity and permissions. Includes `_effective_permissions()` helper that dynamically collects all non-wildcard `PERM_*` constants from `app/security/rbac.py` that the principal has, excluding `PERM_ADMIN`.

3. **backend/app/api/router.py**: Added import for `me` router and `get_principal` dependency. Mounted `/me` router with `dependencies=[Depends(get_principal)]` (authenticated, no additional permission required) with a comment explaining why no permission is needed.

4. **backend/tests/integration/test_me_api.py** (new): Integration tests covering:
   - `test_get_requires_a_principal`: Without a principal returns 401
   - `test_admin_principal`: `admin:*` principal gets `permissions == ["admin:*"]` and all non-wildcard `PERM_*` in `effective_permissions`
   - `test_readonly_principal`: `read:*` principal gets only `read:` constants in `effective_permissions`, no write/admin permissions
   - `test_specific_permissions_principal`: Principal with exactly `{"read:fleet", "alert:ack"}` gets exactly those two
   - `test_email_passed_through`: Email passed through, `null` when absent

5. **docs/tasks/B-1.3.report.md** (new): This report.

## What Was Done

Implemented the `GET /api/v1/me` endpoint as specified in the task:
- Returns the caller's `subject`, `email`, granted `permissions` (sorted), and derived `effective_permissions` (sorted)
- `effective_permissions` dynamically collects every `PERM_*` constant from `app/security/rbac.py` (excluding `PERM_ADMIN`) that `principal.has()` grants
- No additional permission required beyond authentication; the endpoint exposes only the caller's own identity and grants
- No secrets (tokens, headers, settings) appear in the response
- Mounted at `/api/v1/me` with `dependencies=[Depends(get_principal)]`
