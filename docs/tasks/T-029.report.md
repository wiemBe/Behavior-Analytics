- Tests claimed "reference lines copied from the vendor document". Replaced: PAN tests pin the documented field names/positions (copied from the Palo Alto page, including FUTURE_USE slots) and value shapes; FTD tests require every emitted key to be in Cisco's documented 430001 field list or an explicit UNVERIFIED allowlist.
- Renderer citations rewritten to say what was fetched on 2026-10-12 and what is UNVERIFIED; doc section corrected (it claimed the FTD renderer was "verified").

Added: tests for opt-in profiles and validation rejections (mixed profiles, non-vendor format, no vendor profile); doc notes.
