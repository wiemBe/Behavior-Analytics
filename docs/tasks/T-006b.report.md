## Inherited Codex code: what the agent judged wrong and fixed

- The normalizer check was a substring test; it now parses the component.
- `lower_bound` in the traffic query ignored buckets without a metric row and uncollected
  buckets. It now uses lateral aggregates over the source buckets from `first_seen_at` through
  the judged bucket: the counts are a lower bound if any bucket is LOWER_BOUND, or if there are
  fewer buckets than expected. This is fail-closed and goes beyond the spec's letter.
- History slicing was O(n·m); it now uses `bisect`, and endpoints with the same first-seen bucket
  and normalizer share one verification.
