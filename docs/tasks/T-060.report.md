## 2. Review points
1. **Table scroll.** Evidence folds under State and Deviation under Observed → Expected at <= 1280 px; Severity folds under Detector and Started under the Subject at <= 1100 px. Columns stay in the DOM (the pinned nine-header test needs them); CSS (`.col-md/.col-sm` hidden, `.cell-fold.fold-md/.fold-sm` shown) swaps them, so each fact is visible exactly once at any width. Every route, all viewports: 0 local scrollers.
2. **Units.** Every cell carries its unit: `6.10 → 2.00 EPS`, `412 → 41.5 req / 5 min`, `31.8% → 2.1%`. The heading keeps its pinned "(EPS)" on a page of log sources only (see open points).
3. **Header wrap.** `th` is `white-space: nowrap`; text unchanged (pinned).
4. **Subject cell.** Stacked: `METHOD /path` (mono), source link, muted "Virtual host …" only when present. The source is one ellipsized line with the full name in `title`. The old " · " is kept as `sr-only` text so the textContent (and screen-reader reading) stays "GET /portal/login · lab-waf-behavior-01".
5. **Evidence words.** Phase A rows show Not requested / Partial / Complete / Unavailable (new `evidenceLabel`). A WAF row shows "—" with `title` and sr-only "Evidence collection does not apply to WAF anomalies"; no fold copy for WAF.
6. **Detector hyphen.** `td.cell-detector { min-width: 13ch }` (label strings unchanged; tests pin them).
7. **Chip.** Gap between label and the mark; `aria-label="Remove filter Subject: Log sources"`.
8. **Seasonal band.** Per bucket from the cell of the bucket's ISO weekday (Monday = 1, Sunday = 7, UTC hour; checked in `app/anomaly/seasonal.py` `seasonal_key`). The detector's range is the cell's p05..p95 and its expected value the cell's median (`app/waf/behavior.py`, `baseline_low/high = cell.p05/p95`), so the band is labelled "Expected range" and the dashed line "Expected median". A missing or unreliable cell gives null (no band, never zero); gap points have no band. Only the request-rate and ratio detectors use it (novelty has no history by design). If the cells could not be loaded the chart falls back to the flat range at detection and the legend says "Expected range at detection". The lookup is built inside the client chart from plain cell data (a function cannot cross from the server page; found and fixed while capturing).
9. **Ratio detectors.** Primary panel is the detector's own proportion in %: block = blocked_count / action_events (`action_measurement`), 5xx and 4xx = counts / response_code_events (`response_code_measurement`), concentration = top1_client_requests / client_events (`client_measurement`), matching `RATIO_METRICS` and the detectors. Only an EXACT breakdown on a COMPLETE bucket with a non-zero denominator is plotted; NOT_COLLECTED, FAILED, LOWER_BOUND (capped), PARTIAL, null count and zero denominator are gaps, shaded as not collected. Expected: the cells give only the median/p05/p95 of per-bucket proportions, not the pooled sums the detector divides (`numerator_sum/denominator_sum` are not in `WafBaselineCellOut`), so I draw the seasonal p05-p95 band labelled "Seasonal p05–p95 of bucket proportions" and the pooled expected only as a flat line "Expected at detection". Coverage stays the secondary panel. The request count per bucket is in the hover. The "judges a proportion" note is removed.
10. **State words.** `stateLabel` (Insufficient data, Normal, Open, …) in the WAF header pill, the lifecycle (both ends) and the endpoint inventory; same pill classes. The list's State pill is unchanged (pinned raw values on Phase A pages).
11. **Evidence section** removed for WAF.
12. **Against what normal.** Range carries `requests / 5 min`; a ratio shows "Seasonal p05–p95 at detection" in %; a missing range is a dash with sr-only "not recorded for this incident".
13. **Admission wording.** "1,893 refused over quota (key-buckets)", "702 below admission threshold (key-buckets)", a footnote explaining key-bucket, quota and noise, and a `title`. `isOverflowing` now means truncation or quota refusals, never the below-threshold count.
14. **Small items.** Source header separated by dots; the 404's "Open WAF behavior" is a link to `/behavior/waf`; headline says "valid".
- **Fixture**: honours `since`/`until`; Phase A series is a smooth, noisy, plausible one (02:40-15:00) with the anomaly (08:40-08:50) inside; WAF endpoints have seasonal cells (with one unreliable and one missing hour) and a ratio endpoint with not-collected, failed, partial and zero-denominator buckets.

- The list's State pill keeps the raw enum (pinned on Phase A pages). The WAF pages use words.
- A hourly-cell band is drawn stepwise per bucket and is invisible next to a large spike; no axis scaling was added.
