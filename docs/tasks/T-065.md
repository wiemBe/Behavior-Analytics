## Why

T-049 added `QRadarRestProvider.probe_ips_fields` and the pure `app/ips/validation.py`. Two of
its AQL forms have **never run on a live QRadar**:
- the IP population filter `"<ip field>" IS NOT NULL AND "<ip field>" NOT LIKE '127.%' AND
  "<ip field>" != '::1'` (a `LIKE` on an IP-typed field);
- `QIDNAME("qid") LIKE 'Unknown %'`.

If QRadar rejects either, every IPS profile comes out `INVALID` (`FIELD_REJECTED`), and T-050's
collection queries would inherit the same mistake. Find out now.
