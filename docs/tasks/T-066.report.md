### 4.1 The IPS test still fails — a *second*, independent clock bomb (not fixed, not in scope)

After the mandated fix, the target IPS test reaches further and then fails at a different,
later assertion:

```
tests/integration/test_ips_profile_admin.py:403: AssertionError
E   AssertionError: assert 'ips-admin' == 'actor-54'
```

Root cause, with evidence:

1. The test seeds 55 audit rows with `created_at=NOW + timedelta(seconds=index)`
   (`test_ips_profile_admin.py:343`), so the newest seeded row is **2026-10-13 09:00:54 UTC**.
2. Before that assertion it performs real mutations (`disable`, `enable`, `disable`). Each writes
   an audit row through `record_audit`, which stamps `created_at=datetime.now(UTC)`
   (`app/repositories/audit.py:26`) — the **real** clock, currently ~15:1x UTC.
3. The history endpoint returns `ORDER BY created_at DESC, id DESC LIMIT 50`
   (`app/api/routes/ips.py:419`), so the three API-written rows outrank every seeded row and
   `history[0]["actor"]` is `ips-admin`.

Consequences: this assertion only holds while the real clock is before **2026-10-13 09:00:54
UTC**. My edit did not cause it — without my edit the test dies earlier, at the 900 s pending
timeout (09:15 UTC) or on Redis, so this latent failure was simply never reached. It is a separate
time bomb with a slightly earlier trigger than the one T-066 describes.

The equivalent WAF test `test_history_is_newest_first_and_capped` (`test_waf_profile_admin.py:473`)
passes at any clock because it performs no mutating API call before reading history.

I did **not** fix it: the only remedies are an assertion change (forbidden by AGENTS.md §4 and by
the task) or a third setup edit (seed those 55 rows from a real-clock base instead of `NOW`), and
the task says "Change nothing else: … no other use of `NOW`". So the spec's "both files must pass
in full" is currently **not** met, and cannot be met within two edits. Suggested follow-up task:
change `created_at=NOW + timedelta(seconds=index)` at `test_ips_profile_admin.py:343` to a
real-clock base (e.g. `datetime.now(UTC) + timedelta(seconds=index)`), a setup-only change with no
assertion edits.
