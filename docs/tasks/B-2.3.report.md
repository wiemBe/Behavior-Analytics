(found by break-it). The new test uses a mid-hour `until` and both families.

`counts` shape chosen: **non-zero severities only** (an absent severity counted zero; the hour itself is always present,
an empty hour is `{}` with total 0). Documented in `AnomalyHistogramHourOut`'s docstring; pinned by
`test_the_hours_carry_their_counts_in_order` (hour 4 == `{"counts": {}, "total": 0}`), `test_an_empty_range_is_all_measured_zeros`
and unit `test_no_zero_entries_are_synthesized`.

One statement per request: `test_one_statement_whatever_the_data_size` (6 rows, then 106 rows; both `== 1`).
Population equals `GET /anomalies` total: asserted against the list endpoint in several tests.
