## The question each view answers

- **`/anomalies`** (existing): "What is anomalous right now, on which subject?" Add a **Subject**
  column rendering `GET /portal/login · lab-waf-behavior-01` for a WAF row and the source name for a
  Phase A row, and a subject-kind filter (All / Log sources / WAF endpoints). A WAF type shows its
  readable name; never a raw enum string where a word exists.
- **`/anomalies/[id]`** for a WAF subject: "What changed on this endpoint, against what normal?"
  Header names method, endpoint and source. When the source exposes no virtual host, the sentence of
  §27.15 verbatim. Timeline: requests against the seasonal **band** (not three lines), `PARTIAL`
  buckets as gaps, coverage as a secondary series with its own unit. `observed_measurement =
  LOWER_BOUND` renders "≥ n", never `n`. The detection block from `WafDetectionDetailOut`;
  transitions. Phase A-only sections are absent for WAF, not empty shells.
- **`/behavior/waf`**: "Which WAF sources are healthy enough to judge, and where is admission
  overflowing?" Per source: profile enabled and validation status for the current version (link to
  `/admin/waf-sources/<id>` for admins), coverage, active endpoints against the ceiling, admission
  overflow in range.
- **`/behavior/waf/sources/[id]`**: "Which endpoints of this source are tracked, and how adequate is
  each baseline?" Paged endpoint inventory: method + endpoint, baseline adequacy, last seen (UTC),
  retired, state (worst detector state; `null` = not evaluated, said in words).
- Nav: one entry for `/behavior/waf` in the existing behavior group (update the pinned nav test for
  exactly that entry).

## Honesty (§3a, guidelines §4/§6)

Unmeasured renders as an em dash with its meaning, a measured zero as `0`; `null` never becomes `0`.
INSUFFICIENT_DATA, PARTIAL, LOWER_BOUND and "not evaluated" are designed states. Times in UTC with
the zone. Numbers right-aligned, tabular, with units (requests, %, req/5 min — whatever the API's
unit is; say it).
