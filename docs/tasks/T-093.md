# Task T-093 — the WAF detection block forwards the detector's caveat

Read `AGENTS.md` at the repository root first. Follow it exactly.

## Why

Every WAF detector stores a fixed interpretive caveat in its evidence, under `extra["caveat"]`
(`backend/app/waf/behavior.py`: the ratio detectors through `d.caveat`, the source concentration
detector "A dominant source IP describes traffic composition, not intent.", and the new-endpoint
detector "A newly requested endpoint may be a deployment as easily as a probe."). The analyst API
cannot show it: `WafDetectionDetailOut` (`backend/app/schemas/anomaly.py`) is a whitelist and has no
`caveat` field. The IPS block already has one (`IpsDetectionDetailOut.caveat`, projected with
`_text(extra, "caveat")`). Found in T-090's report, open point.

## Build

1. `WafDetectionDetailOut`: add `caveat: str | None = None`, with a `#:` comment in the voice of
   the IPS one ("The detector's fixed interpretive caveat ..."). Place it after
   `percentage_point_change`, before `ratio`.
2. `waf_detection_detail`: `caveat=_text(extra, "caveat")`. Nothing else changes; contributor lists,
   the entity block and provenance stay out.

## Tests (in `backend/tests/unit/test_waf_analyst_schemas.py`)

- The caveat is forwarded when the evidence carries one in `extra` (use the new-endpoint text).
- It is `None` when absent, and `None` when it is not a string (for example `{"caveat": 3}`).
- The existing whitelist test (`set(dumped) == set(WafDetectionDetailOut.model_fields)`) keeps
  passing without edits. Do not edit any existing test.
- One test that runs a real WAF detector's evidence through the projection: build the evidence the
  way an existing WAF detector test in `backend/tests/unit/` already does (find one that produces a
  new-endpoint or a ratio verdict's details dict), then assert `waf_detection_detail(...).caveat`
  equals that detector's caveat text. If no existing test builds such a details dict cheaply, say
  so in the report and skip only this one test.
- **Break-it:** remove the `caveat=` line from the projection, confirm the new tests fail, restore.
