## The problem

`backend/pyproject.toml` sets `asyncio_mode = "auto"`, so pytest-asyncio already runs every async
test without a mark.

`backend/tests/integration/test_waf_collection.py` line 41 still sets:

```python
pytestmark = [pytest.mark.integration, pytest.mark.asyncio]
```

The module-level asyncio mark therefore also lands on the five **sync** tests in `TestFolding`,
and pytest emits one `PytestWarning` for each: "marked with '@pytest.mark.asyncio' but it is not
an async function".

## The change

In that one file, change line 41 to:

```python
pytestmark = pytest.mark.integration
```

Change nothing else in that file.
