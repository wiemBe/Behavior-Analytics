Linux-hosted SOC tool. The two criticals and the high that the production audit surfaces are blocked

## Recommendation

### 1. Do now — one small, safe patch task

* **`next` 15.5.22 → 15.5.28** (patch within 15.5.x). Clears all four Next advisories
  (criticals at 15.5.24, cache poisoning at 15.5.27; 15.5.28 is the current 15.5.x). None of them is
  reachable today, but the upgrade is free and removes the critical findings from the report.
* **`sharp` → 0.35.5** (Next's optional range is `^0.34.3 || ^0.35.5`, so no direct-dep bump). Clears
  the three `sharp` advisories. Unused today, but bundled with the image optimizer.
* **`npm update` of the lockfile within existing ranges** to clear the dev/build transitives that have
  a non-breaking fix already allowed by their parents: `nanoid` ≥3.3.18, `source-map-js` ≥1.2.2,
  `browserslist` ≥4.28.7, `baseline-browser-mapping` ≥2.11.0, `js-yaml` ≥4.3.2, `brace-expansion`
  1.1.21 (under `eslint`) and 5.0.12 (under `eslint-config-next`), `micromatch`/`fast-glob` are not
  fixable this way (see below).
* **`echarts-for-react` 3.0.2 → 3.0.6** (non-major) even though its only advisory rides on echarts
  and is not reachable.
* **`postcss`** cannot be cleared by a normal bump because `next` pins `8.4.31` exactly. Either add an
  `overrides` entry (`"postcss": "8.5.23"`) in this task (verify `next build` still passes — Next only
  uses postcss at build time), or accept it and note it. The other copy (under vite 5.4.21) can be
  `npm update`d to 8.5.23 today.

### 2. Plan a major upgrade — dev/test toolchain

* **`vitest` 2.1.8 → 4.1.11+** (major). This is the only version that clears the whole test chain:
  GHSA-82fw (`@vitest/mocker` ≥4.1.11), `tinypool` 1.x (vitest 4 no longer depends on tinypool),
  the two vitest criticals (≥3.2.6) and the vite advisories (vitest 4 pulls vite 6/7). It also drops
  `vite-node` and `esbuild ≤0.24.2`. Expect test-config changes (`vite-node` removal, possible jsdom /
  testing-library bumps). Also bump `@vitejs/plugin-react` and `jsdom` to their current majors.
* **`echarts` 5.5.1 → 6.1.0** (major) — only worth doing as part of that batch; the XSS is not
  reachable, and echarts 6 is a charting API change, so treat it as low priority.

### 3. Dev-only, low priority / currently unfixable

* **`braces`** (`GHSA-vfj7-8cjw-p6xm`) has **no patched version**; `fast-glob`, `micromatch` and
  `@next/eslint-plugin-next` inherit it. `npm audit`'s suggested remedy is a *downgrade* of
  `eslint-config-next` to 14.2.35 (which uses `glob` instead of `fast-glob`). Do not do that for an

* `esbuild`, `vite`, `vite-node`, `@vitest/mocker`, `tinypool`, `js-yaml`, `browserslist`,
  `baseline-browser-mapping`, `brace-expansion` — all test/lint/build tooling, none exposed in the
