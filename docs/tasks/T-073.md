# Task T-073 — "never validated" instead of "(last validated: None)" (WAF and IPS)

Read `AGENTS.md` at the repository root first. Follow §4: never weaken, skip or delete a test.

## The defect

`profile_ineligibility` in `backend/app/waf/profile.py` (around line 257) and in
`backend/app/ips/profile.py` (around line 283) builds:

```python
f"profile version {profile.profile_version} has not been validated "
f"(last validated: {profile.validated_profile_version})"
```

When the profile has never been validated, `validated_profile_version` is `None`, so operators
read `"(last validated: None)"` in the API and the UI.

## The fix

In **both** functions, only when `profile.validated_profile_version is None`, return exactly:

```python
f"profile version {profile.profile_version} has never been validated"
```

Otherwise keep the existing string unchanged. The existing test
`tests/integration/test_waf_productionization.py` (around line 227) pins
`"profile version 2 has not been validated (last validated: 1)"`, and it must stay green unchanged.

## Tests

Add unit tests (new test functions; change no existing test) that cover, for WAF and for IPS:
- the never-validated case gives the new string;
- a stale case (an older validated version) gives the old string with that version.

Look for the closest existing unit test module for each `profile_ineligibility` and add the tests
there. If there is none, create `tests/unit/test_profile_ineligibility.py`.

Break-it: revert one function, see its test fail, restore it.
