## 2. What you did / acceptance criteria

- A classified WAF source's alert carries `context["source_class"] == "WAF"`; a
  `RoutingRule(source_classes=frozenset({"WAF"}))` matches it and the dispatcher notifies only
  that route; a refresh of the still-open condition keeps the class.
- An unclassified WAF source: the key is absent from `context` (asserted via
  `"source_class" not in context`), and a class-scoped route resolves to no routes and no
  notification.
- A route restricted to `{"FIREWALL"}` does not match a `WAF`-classified alert.
- Fingerprint identical with and without a classification row: pinned both against the explicit
  `waf_anomaly_fingerprint(...)` call and across a classify-mid-incident resolve/recur episode.
- Statement count measured before and after (scratch scripts kept outside the repository, in
  `/tmp/opencode/`):
  - single-endpoint run with opens (replica of `test_waf_alerting.py`'s `evaluate` +
    dispatcher): **18 statements before, 19 after**; the one new statement is
    `SELECT qradar_instance.name, log_source_classification.source_class FROM qradar_instance
    LEFT OUTER JOIN log_source_classification ... WHERE qradar_instance.id = ...`, executed once
    per run with opens, never per endpoint.
  - Why not exactly zero: before the change the engine's `session.get(QRadarInstance, ...)`
    cost **0** statements in the scheduled path (`run_waf_source` loads the instance into the
    same session first, and `expire_on_commit=False`), so an identity-map hit replaced by one
    select is +1 constant per run-with-opens. Reading the class from the DB requires one round
    trip at best; the task's suggested single joined statement is that floor, so "no new
    statement per run" was not achievable.
- Statement-count pins checked — **no pinned count changed**, so no stop was required:
  - `test_waf_scale.py::test_alert_transition_statement_cost_is_bounded` (replica measured
    before/after): `shadow_open=7`, `paging_open=14→15`, so `open_cost=7→8`, still inside the
    pinned `0 < open_cost <= 8`; `resolve_cost=5` unchanged (the resolve run has no opens, so
    the lookup does not run).
  - `test_waf_scale.py::test_alerting_without_transitions_adds_at_most_one_statement` — no
    opens, lookup not executed; passes.
  - `test_waf_scale.py::test_refreshing_every_open_alert_is_constant_cost` — the lookup is one
    per run, both sizes shift by the same +1; `costs[40] == costs[800]` holds.
  - `test_waf_keyed_collection.py::test_the_statements_per_tick_are_constant_per_bucket` —
    alerting disabled by default; unchanged, passes.
  - `test_waf_alerting.py` — no statement pins; passes unchanged (its exact-equality context
    assertion still holds because the test source has no classification row).
