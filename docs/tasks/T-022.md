## Tests

- **Unit, `classify()`.**
  - Every precedence level wins over the ones below it.
  - Override beats everything.
  - The internal rule holds.
  - Equal-priority conflicting rules give a conflict and fall through.
  - A lower-level disagreement is recorded as a conflict.
  - A catch-all type falls through to the name.
  - The group-ancestor walk works, including the root/0 case.
  - Regex is case-insensitive with word boundaries (`dmz-ips-01` → IPS; `lipstick` is not IPS).
  - Determinism: the same inputs give the same output.
- **Unit, REST parsing** of a 7.6-shaped row: epoch ms, the identifier, a status object.
- **Integration, sync.**
  - The first sync gives all sources REVIEWED and raises no alerts.
  - A second sync with one new source gives exactly one NEW source and one inventory alert.
  - A re-sync is idempotent: no second alert.
  - An override survives a re-sync.
  - Types and groups are upserted.
  - A groups failure still lets the sync succeed.
- **Integration, statement count.** Syncing 50 versus 1,000 sources costs the same number of
  statements, or grows only with bulk chunks. Pin it, in the style of
  `tests/integration/test_waf_scale.py`.
- **Migration** round-trip test.

After writing the tests, break the code on purpose (the precedence order, the bootstrap rule, the
alert gate), confirm the tests fail, then restore it.
